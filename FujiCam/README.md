# FujiCam — แอพกล้องฟิล์มสไตล์ฟูจิ (Android)

## ดาวน์โหลด APK จาก GitHub (ไม่ต้องมีคอมพิวเตอร์)
ทุกครั้งที่อัปโหลดโค้ดขึ้น GitHub ระบบจะ build แอพให้อัตโนมัติ
1. เข้าแท็บ **Actions** ในหน้า repo แล้วเลือกรายการล่าสุดที่มีเครื่องหมายถูกสีเขียว
2. เลื่อนลงไปที่ **Artifacts** แล้วกดดาวน์โหลด **FujiCam-apk** (ได้ไฟล์ zip ที่มี FujiCam.apk อยู่ข้างใน)
3. แตก zip แล้วเปิด FujiCam.apk บนมือถือเพื่อติดตั้ง (อาจต้องอนุญาต "ติดตั้งแอพที่ไม่รู้จัก")

ถ้าอยากได้ลิงก์ดาวน์โหลดถาวร ให้ไปที่ **Releases › Draft a new release** ตั้งชื่อแท็กขึ้นต้นด้วย `v` เช่น `v1.0` แล้วกด Publish ไฟล์ APK จะถูกแนบให้อัตโนมัติ

ถ้า build ไม่ผ่าน (กากบาทสีแดง) ให้กดเข้าไปดูข้อความ error ในขั้นตอน **Build APK**

หมายเหตุ: กุญแจเซ็นแอพ (app/fujicam.keystore) อยู่ในโปรเจกต์ ใช้สำหรับติดตั้งเองเท่านั้น ถ้าจะลง Play Store ให้สร้างกุญแจใหม่และเก็บเป็นความลับ

## วิธี build ด้วย Android Studio
1. ติดตั้ง Android Studio (เวอร์ชัน Ladybug 2024.2 ขึ้นไป)
2. แตกไฟล์ zip แล้วเลือก **File › Open** ที่โฟลเดอร์ `FujiCam`
3. รอ Gradle sync เสร็จ (ครั้งแรกจะโหลดไลบรารีสักพัก)
4. เสียบมือถือ (เปิด USB debugging) แล้วกด **Run ▶**
   หรือสร้างไฟล์ติดตั้งที่ **Build › Build App Bundle(s)/APK(s) › Build APK(s)**

ต้องใช้ Android 10 ขึ้นไป รูปจะอยู่ที่ `Pictures/FujiCam` และวิดีโอที่ `Movies/FujiCam`

## ฟีเจอร์
- หน้ากล้องแบบไอโฟน: โหมด รูปถ่าย / วิดีโอ / ถ่ายคู่ / อัดคู่, ปุ่มชัตเตอร์, รูปล่าสุด, สลับกล้อง
- ฟิลเตอร์ 47 แบบ แบ่งหมวด Film Simulation / ฟิล์มฟูจิ / สูตรฟิล์ม / ขาวดำ / ครีเอทีฟ เห็นผลสดบนกล้อง ปรับความเข้มได้
- ซูม 1× 2× 3× 4× 5× (และ 0.5× ถ้ามีเลนส์มุมกว้าง) + บีบนิ้วซูม
- แตะโฟกัส, ปรับแสง (EV), แฟลช/ไฟฉาย, ตั้งเวลา 3/10 วิ, เส้นตาราง, ดับเบิลแตะสลับกล้อง
- กดปุ่มเพิ่ม/ลดเสียงเพื่อถ่าย, กลับด้านรูปกล้องหน้าแบบกระจก
- วันที่สีส้มแบบกล้องฟิล์ม, เกรนฟิล์ม, ขอบมืด, แสงรั่ว
- อัดวิดีโอ HD/4K, หยุดชั่วคราวได้, กดถ่ายภาพนิ่งระหว่างอัด, ใส่สีฟิลเตอร์ให้วิดีโอหลังอัดเสร็จ
- ถ่ายคู่หน้า-หลังพร้อมกัน (บันทึกภาพรวม + แยก 2 ไฟล์) และอัดวิดีโอคู่ (ได้ 2 ไฟล์)
- แคปเฟรมจากวิดีโอที่ความละเอียดเต็ม เลื่อนทีละเฟรม บันทึกเป็น PNG ไม่บีบอัด
- นำเข้ารูปจากแกลเลอรี่มาแต่ง: ฟิลเตอร์, ความสว่าง, คอนทราสต์, ความอิ่มสี, อุณหภูมิสี, เขียว-ม่วง, ซีดจาง, เกรน, ขอบมืด, หมุนภาพ, แตะค้างเทียบต้นฉบับ, บันทึกที่ความละเอียดเต็ม

- แก้: วิดีโอกล้องหน้าและอัดคู่กลับด้านแบบกระจกตามสวิตช์ในตั้งค่า
- แก้: กลับมาจากอัลบั้ม/หน้าแต่งรูปแล้ว โหมด กล้อง แฟลช ตั้งเวลา ซูม และค่าปรับแสงยังเหมือนเดิม
- แก้: หน่วยความจำรั่วตอนเปิดถาดฟิลเตอร์ทิ้งไว้ และลบโฟลเดอร์ว่างที่ชื่อผิด
- อัดคู่แบบบน-ล่าง: พรีวิวแบ่งครึ่งจอจริง และพรีวิวอัดคู่เป็นสัดส่วน 9:16 เท่ากับไฟล์

- ลดข้อความเด้งในจุดที่เห็นผลบนจออยู่แล้ว
- ฟิล์มใหม่ 5 ตัว พร้อมม้วน: CineStill 400D, Pro 160NS, ColorPlus 200, Ektar 100, Aerochrome IR

## ใหม่ในเวอร์ชัน 1.3
- อัลบั้มในแอพ: รูปล่าสุดขึ้นมุมซ้ายล่างตั้งแต่เปิดแอพ แตะเพื่อเปิดอัลบั้ม มีแท็บ ทั้งหมด / สมุดฟิล์ม (จัดกลุ่มตามม้วน) / วิดีโอ / ต้นฉบับ ดูเต็มจอ เลื่อนดู แชร์ แต่ง แคปเฟรม ลบ
- ถ่ายคู่บันทึกภาพรวมไฟล์เดียวเป็นค่าเริ่มต้น (เปิดเก็บภาพแยกได้ในเมนู ⋮)
- ถ่ายคู่/อัดคู่: แตะกรอบเล็กเพื่อสลับจอใหญ่ ลากกรอบเล็กไปมุมไหนก็ได้ (มีผลทั้งรูปและวิดีโอรวม)
- ยุบฟิลเตอร์ที่คล้ายกันเป็นแบบย่อย: แถบหลักเหลือ 42 ตัว อีก 25 ตัวเป็นปุ่มแบบย่อยเมื่อเลือกตัวแม่ (เช่น ACROS → +Ye / +R / +G / Monochrome)
- แถบบนเหลือ 4 ปุ่ม: ปุ่มฟิลเตอร์และปรับแสงย้ายมาข้างชัตเตอร์ เส้นตารางย้ายไปเมนู ⋮
- พรีวิวแสงฟุ้งอัปเดตทุก 0.6 วินาที ปิดได้ในเมนู (มือถือแรมน้อยปิดไว้ตั้งแต่แรก) รูปจริงยังมีแสงฟุ้งครบ
- หน้าแต่งรูปและแต่งหลายรูปเลือกสัดส่วนได้ (ต้นฉบับ / 4:3 / 3:2 / 1:1 / 16:9 / 65:24) และสูตรจำสัดส่วนไว้ด้วย
- แชร์สูตรเป็นโค้ด (FJR1:...) และวางโค้ดสูตรของคนอื่นมาใช้ได้
- จำจำนวนภาพที่เหลือแยกตามม้วน สลับม้วนไปมาได้ไม่รีเซ็ต และตั้งให้ใส่ม้วนใหม่อัตโนมัติเมื่อหมดได้

## ใหม่ในเวอร์ชัน 1.2
- ⭐ ฟิลเตอร์โปรด: แตะค้างที่ฟิลเตอร์เพื่อปักหมุด ฟิลเตอร์โปรดขึ้นหน้าสุดเสมอ และมีปุ่มดูเฉพาะโปรด
- ค้นหาฟิลเตอร์ด้วยชื่อ (ไอคอนแว่นขยายในแถบฟิลเตอร์)
- สัดส่วนภาพ 4:3 / 3:2 / 1:1 / 16:9 / 65:24 (พาโนรามา XPan) มีแถบบังให้เห็นกรอบตอนถ่าย
- บันทึกรูปต้นฉบับคู่กัน (Pictures/FujiCam/Originals) เปิดได้ในเมนู ⋮
- แสงฟุ้งรอบดวงไฟ: Halation (ฟุ้งแดง) และ Bloom (ฟุ้งขาว) ฟิลเตอร์กลางคืนมีค่าตั้งต้นให้ ปรับเพิ่มได้ และเห็นผลบนจอกล้อง
- ขอบภาพใหม่ "ขอบขาว+ข้อมูลฟิล์ม" พิมพ์ชื่อโทนฟิล์มและวันที่ใต้ภาพ
- สูตรของฉัน C1–C5 ในหน้าแต่งรูป และแต่งหลายรูปพร้อมกัน (เมนู ⋮ หรือแท็บสูตรของฉัน)
- อัดคู่รวมเป็นไฟล์เดียวได้ แบบกรอบเล็ก (PiP) หรือแบ่งบน-ล่าง (ทดลอง)
- แถบเปอร์เซ็นต์ตอนใส่ฟิลเตอร์/รวมวิดีโอ พร้อมปุ่มข้ามเพื่อเก็บไฟล์ต้นฉบับ
- ซ่อนโหมดถ่ายคู่/อัดคู่อัตโนมัติถ้ามือถือไม่รองรับ

- ขอบภาพ: ขอบขาว / แถบฟิล์มเนกาทีฟ / อินสแตนท์ (ใช้ได้ทั้งโหมดฟิล์มและหน้าแต่งรูป)
- เซ็นแอพด้วยกุญแจตายตัว อัปเดตทับเวอร์ชันเก่าได้โดยไม่ต้องถอนก่อน (ยกเว้นครั้งแรกที่อัปจาก 1.0)

## ข้อจำกัด
- ฟิลเตอร์เป็นการเลียนแบบโทนสี ไม่ใช่ไฟล์ LUT ทางการของ Fujifilm
- ถ่ายคู่/อัดคู่ ใช้ได้เฉพาะมือถือที่รองรับ Concurrent Camera และระบบจะจำกัดความละเอียดในโหมดนี้
- วิดีโอได้เฉพาะสีของฟิลเตอร์ (เกรน ขอบมืด วันที่ ใส่ได้เฉพาะรูปถ่าย)

## โครงสร้างโค้ด
- `filters/` เมทริกซ์สี รายการฟิลเตอร์ และตัวเรนเดอร์ (เพิ่มฟิลเตอร์ใหม่ได้ใน `FilmLooks.kt`)
- `camera/` CameraX (กล้องเดี่ยว/คู่ ถ่าย อัด) และ Media3 (ใส่ฟิลเตอร์วิดีโอ, ดึงเฟรม)
- `ui/` หน้ากล้อง หน้าแต่งรูป หน้าแคปวิดีโอ
